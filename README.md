# LG360-CAM-Control
Aplicación Android experimental para LG 360 CAM R105. Conecta el teléfono al Wi-Fi LGR105_....OSC antes de abrir la aplicación.

Funciones de prueba: consultar /osc/info, /osc/state y ejecutar camera.takePicture por OSC en 192.168.43.1:6624. La compatibilidad de cada comando debe comprobarse en el dispositivo real. No incluye vista previa ni descarga de fotos todavía.

## APK
En GitHub abre Actions > Build Debug APK > último run exitoso > Artifacts > LG360-CAM-Control-debug. No necesitas Android Studio.
